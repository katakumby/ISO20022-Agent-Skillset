# Branch

[src-000162](../../../evidence/omitted/530a772f5cf631826741f05d.md)

## Definition, context and responsibilities

An account at a receiving agent branch can support reimbursement when the sender knows an intra-group agreement permits it. (P174; P217; P224; P300)

Classification: Narrative institutional relationship.

## Relationships

- [head office](participant-src-000162-head-office.md)
- [account servicer](participant-src-000162-account-servicer.md)

## Limits and identifier schemes

This is a permitted account-servicing scenario, not a universal equivalence of branch and head office.
