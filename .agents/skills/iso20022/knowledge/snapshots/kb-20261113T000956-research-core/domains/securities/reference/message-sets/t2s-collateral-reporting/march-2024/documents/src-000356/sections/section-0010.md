**P84** Groups of MessageDefinitions and Functionality

**P85** The collateral reporting messages are specifically designed to query the current available value of securities used in T2S for auto-collateralisation management.

**P86** These messages are to be used with the ISO 20022 Business Application Header (head.001). The schema and more information about the Business Application Header (BAH) can be found on the www.iso20022.org web site
