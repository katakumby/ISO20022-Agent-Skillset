**P98** Scope

**P99** The scope of this set of MessageDefinitions is similar to the one embraced by the ISO 15022 corporate action messages (MTs 564, 565, 566, 567, 568), complemented by an additional message to support the corporate action instruction statement business process. 

**P100** The scope of this set of MessageDefinitions does not include issuers Agent communication. It does not include the general meeting / proxy voting processes as they are covered by another set of MessageDefinitions (see the General Meeting ISO 20022 solution).
