# Intermediary

Business context: Investment Funds. Source classification: functional participant role.

## Definition

Party that receives an instruction from the instructing party and transmits it to the executing party.

Evidence: [T18](../../../domains/securities/reference/message-sets/investment-funds/2025-2026/documents/src-000095/tables/tbl-0018.md), source row 4.

A functional participant role describes involvement in a relationship or transaction. It is not an assertion that a particular institution always plays that role.
