**P118** Securities Account Report (reda.021)

**P119** Securities Account Report (reda.021) is sent to the Instructing Party and includes all of the Securities Account records that meet the specified criteria or reports any possible error (e.g. not allowed set of search criteria). 

**P120** This query response contains the timestamp specifying the system time when the data selection was actually performed.

**P121** The Securities Account Report is capable to report any piece of information related to a securities account, including securities account identification, opening and closing date, hold indicator default value, negative position indicator, securities account type, securities account owner, party type; market specific attribute, restriction, end investor flag, pricing scheme.
