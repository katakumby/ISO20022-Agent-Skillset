**P527** Split Settlement

**P528** The split settlement consists (for an instructing/splitting party) in requesting the replacement of an existing instruction by two or more instructions. This is typically done by CSD Participants (unilaterally or bilaterally) to for example, enable the settlement of a client instruction that is short. Unilateral splitting is when only one party instructs the split. This happens for example in the UK.
