Source top header merges “ISO 20022 message ...” over the last two columns. Footnote 1: the ISO 20022 catalogue labels messages without duplicated BAH elements “The message definitions below are intended for use with the Business Application Header.” The surrounding text says each implementing community decides whether to use BAH. Without either BAH or duplicated fields, BusinessMessageIdentifier and CreationDate cannot be conveyed through those mechanisms. The guide asks communities unable to deploy BAH to contact the Registration Authority for implementation advice; non-ISO mechanisms such as network headers may not implement every MUG scenario. These are historical guide statements, not a current catalogue lookup.

| --- | --- | --- |
