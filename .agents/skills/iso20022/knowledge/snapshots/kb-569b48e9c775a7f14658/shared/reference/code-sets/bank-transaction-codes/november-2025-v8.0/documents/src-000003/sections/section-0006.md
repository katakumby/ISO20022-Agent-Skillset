# Scope of the Bank Transaction Code

**P91** Scope of the Bank Transaction Code

**P92** The scope of the Bank Transaction Code is to deliver a harmonised set of codes, which should be applied in bank-to-customer cash account reporting information. The bank transaction code information allows the account servicer to correctly report a transaction, which in its turn will help account owners to perform their cash management and reconciliation operations.

**P94** The Bank Transaction Code proposes a harmonised, global alternative for the different domestic bank transaction code sets that exist. The lack of such a harmonised set led to a misuse and misinterpretation of the domestic codes.

**P96** The requirements that have been expressly identified as part of the scope of the Bank Transaction Code are the following:

**P97** All transactions resulting in a cash movement on the customer’s account should be taken into account;

**P98** Usage of national bank transaction code sets should be catered for initially in order to ease the migration from the existing sets towards the harmonised bank transaction code set. 

**P99** The existing domestic bank transaction code sets need to migrate towards the standardised set for consistency and interoperability.

**P100** Clear definitions of the bank transaction codes are required so that the same code is always used in the same context and two codes may not be used for the same transaction. 

**P101** The bank transaction code is used to allow the reconciliation between the reason of the cash movement and the sub-ledger and/or the routing of the information to the adequate processing system at the customer side.
