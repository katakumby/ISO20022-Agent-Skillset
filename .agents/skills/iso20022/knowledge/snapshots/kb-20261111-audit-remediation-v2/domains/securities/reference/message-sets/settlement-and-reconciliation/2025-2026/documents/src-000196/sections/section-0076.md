**P456** Modification

**P457** The modification process covers the following processing changes and the reporting surrounding this process. These processing changes are:

**P458** Automatic Borrowing Indicator: Specifies whether automatic borrowing needs to take place to achieve settlement.

**P459** Retain Indicator: Specifies whether a failed instruction due to expire should be retained.

**P460** Linking Indicator: Specifies what linkage action needs to be performed.

**P461** Priority Indicator: Specifies the execution priority of the instruction.

**P462** Partial Settlement Indicator: Specifies whether partial settlement is allowed.

**P463** Securities Real-Time Gross Settlement Indicator: Specifies whether settlement is to be executed through an RTGS system.

**P464** Hold Indicator: Specifies whether instruction is to be presented for settlement.

**P465** The scenarios below describe two examples of processing changes when:

**P466** the on hold original instruction is being released and

**P467** the released original instruction is being held then released.
