# Code publications

Find the specific external-code set or bank-transaction-code publication. Read its identity, edition basis, applicability, limitations and complete relevant rows.

Preserve identifiers and leading zeros, code meanings, valid/withdrawn status and date fields when supplied, hierarchy, units and footnotes. Follow table-part continuations before making an exhaustive claim.

An external XSD code-type name does not enumerate its separately published values. Some supplied external-code definitions have no supplied enumeration; report that gap. Filename dates and message versions do not establish publication applicability. Retain an unknown or disputed publication edition as such.

Do not call the embedded list current beyond its supported edition. There is no online fallback or external research. Return the local publication identity and source locator with the answer.

For code combinations, preserve the published domain/family/subfamily relationship and conditions. Do not invent combinations from individually valid values.
