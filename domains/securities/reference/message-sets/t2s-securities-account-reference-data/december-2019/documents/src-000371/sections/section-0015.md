**P97** Securities Account Modification Request (reda.023)

**P98** Securities Account Modification Request (reda.023) provides a user, granted with the appropriate rights, with the possibility to update an active and valid securities account.

**P99** The Securities Account Status Advice (reda.020) informs the Instructing Party about the lifecycle of its securities account modification request.
