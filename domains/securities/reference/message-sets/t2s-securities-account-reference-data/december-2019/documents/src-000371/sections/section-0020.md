**P125** Securities Account Audit Trail Query (reda.036)

**P126** Securities Account Audit Trail Query (reda.036) is sent by an authorised party to query on audit trail for securities account reference data. 

**P127** Depending on the query criteria, it is possible that the processing will take more than a certain time or that the query will not retrieve any record. In this case, an error is sent to the Instructing Party within the Securities Account Audit Trail Report message.

**P128** Search criteria include the following elements: 

**P129** Securities account identification;

**P130** Date Period.
