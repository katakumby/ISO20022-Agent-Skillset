**P100** Securities Account Deletion Request (reda.032)

**P101** Securities Account Deletion Request (reda.032) provides a user, granted with the appropriate rights,  with the possibility to delete an existing securities account. 

**P102** The Securities Account Status Advice (reda.020) informs the Instructing Party about the lifecycle of its securities account deletion request.
