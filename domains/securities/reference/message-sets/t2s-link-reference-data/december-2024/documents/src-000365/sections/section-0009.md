**P47** Scope

**P48** As described in the ISO 20022 Business Justification, The candidate Link Reference Data messages are specifically designed to support the management of Links on both Securities CSD and Account sides.

**P50** These messages are to be used with the ISO 20022 Business Application Header (head.001). The schema and more information about the Business Application Header (BAH) can be found on the www.iso20022.org web site
