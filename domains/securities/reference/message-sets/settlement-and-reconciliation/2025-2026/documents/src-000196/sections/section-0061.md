# Transaction Generation Process

Source: [src-000196](../../../../../../../../../raw-input/settlement_and_reconciliation/ISO20022_MDRPart1_SettlementAndReconciliation_2025_2026_v2.docx). Locator: heading path Description of BusinessActivities / Transaction Generation Process.

**P313** Transaction Generation Process

**P314** In this scenario, an executing/servicing party sends a SecuritiesSettlementTransactionGenerationNotification to an instructing party to advise the instructing party of a securities settlement transaction that has been generated/created by the executing/servicing party for the instructing party.

**P315** The reason for creation can range from the automatic transformation of pending settlement instructions following a corporate event to the recovery of an account owner transactions’ database initiated by its executing/servicing party.
