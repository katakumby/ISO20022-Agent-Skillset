**P102** Background

**P103** This Message Definition Report covers a set of sixty-four MessageDefinitions developed by SWIFT in close collaboration with the investment funds community and approved by the Securities SEG on 27January 2026. 

**P104** Many of these messages are ISO 20022 MessageDefinitions approved by the Securities Standards Evaluation Group (SEG). 

**P105** These funds messages are specifically designed to support the investment fund community for account management, orders (including alternative/hedge funds), price report, fund cash forecast, fund reference data, portfolio transfer, transfer and statements.

**P106** The detailed description of each message standard is provided in Funds Message Definition Report Part 2.
