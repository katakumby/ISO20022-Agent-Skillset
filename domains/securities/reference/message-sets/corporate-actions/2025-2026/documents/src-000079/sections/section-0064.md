**P322** Conventions used in flow diagrams

**P323** The message flow diagrams are colour coded for ease of reference with the following conventions: 

**P324** Black = Mandatory message flow 

**P325** Blue = Optional message flow

**P326** Orange = Movement Preliminary Advice and Cancellation Advice message flow
