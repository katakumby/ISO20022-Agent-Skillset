**P91** These Collateral query messages are foreseen to support the following message usages:  


**P92** The Total collateral value per Cash Account Query/Response allows the system user to query the total current collateral value of securities that is earmarked and available (on stock) for auto-collateralisation for a cash account.

**P94** The Collateral value per Cash Account Query/Response allows the system user to receive information on the collateral value of securities on stock per Cash Account and per security.

**P96** The Collateral value of a security Query/Response allows the system user to query for a specific security the current collateral value of the security, earmarked and available (on stock) for auto-collateralisation, in every securities account linked to a specific cash account.

**P98** See Message Definition Report Part 2 for the message and formats.
