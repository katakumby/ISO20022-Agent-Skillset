# authorised representative — Investment Funds Functionality

[src-000096](../../../evidence/omitted/fffd4ab68b421d059524ec38.md)

## Definition and business context

Representative authorised by the investment manager, explicitly named as an alternative example participant in the quoted investment-funds message contexts. The exact clause determines whether this representative is an example sender or recipient; no universal intermediary or order-instructing capacity is inferred.

This record collects the literal role within this publication. It does not equate that function with a particular institution or with a differently scoped role having the same name.
