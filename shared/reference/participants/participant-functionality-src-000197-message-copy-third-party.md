## Definition and business context

Third party receiving an informational copy or re-sent copy of the current message, using BAH facilities where stated. This copying role does not establish settlement-instruction or transaction-audit-trail responsibilities.

This record collects the literal role within this publication. It does not equate that function with a particular institution or with a differently scoped role having the same name.
