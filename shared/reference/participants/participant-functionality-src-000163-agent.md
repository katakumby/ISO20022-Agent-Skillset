# agent — Payments Clearing and Settlement Functionality

[src-000163](../../../raw-input/payments_clearing_and_settlement/ISO20022_MDRPart2_PaymentsClearingandSettlement_2025_2026_v1.pdf)

## Definition and business context

Generic agent function explicitly named in this publication’s quoted message Functionality. Its precise capacity and counterparties are retained per clause rather than being inferred from the generic label.

This record collects the literal role within this publication. It does not equate that function with a particular institution or with a differently scoped role having the same name.

## Responsibilities, actions and relationships

The complete evidence below preserves who acts, the counterparties, alternatives and conditions. Only explicit clauses establish directions; quoted examples remain examples.

### src-000163-pacs.002.001.16-p6-c001

src-000163, file page 6; 2 pacs.002.001.16 FIToFIPaymentStatusReportV16.

> The FIToFIPaymentStatusReport message is sent by an instructed agent to the previous party in the payment chain.

### src-000163-pacs.002.001.16-p6-c004

src-000163, file page 6; 2 pacs.002.001.16 FIToFIPaymentStatusReportV16.

> The FIToFIPaymentStatusReport message is exchanged between agents to provide status information about instructions previously sent.

### src-000163-pacs.002.001.16-p6-c005

src-000163, file page 6; 2 pacs.002.001.16 FIToFIPaymentStatusReportV16.

> Its usage may be governed by a bilateral or multilateral agreement between the agents.

### src-000163-pacs.002.001.16-p6-c006

src-000163, file page 6; 2 pacs.002.001.16 FIToFIPaymentStatusReportV16.

> The FIToFIPaymentStatusReport message can be used to provide information about the status (e.g. rejection, acceptance) of a credit transfer instruction, a direct debit instruction, as well as other intra- agent instructions (for example FIToFIPaymentCancellationRequest).

### src-000163-pacs.003.001.12-p132-c001

src-000163, file page 132; 3 pacs.003.001.12 FIToFICustomerDirectDebitV12.

> The FinancialInstitutionToFinancialInstitutionCustomerDirectDebit message is sent by the creditor agent to the debtor agent, directly or through other agents and/or a payment clearing and settlement system.

### src-000163-pacs.004.001.15-p246-c001

src-000163, file page 246; 4 pacs.004.001.15 PaymentReturnV15.

> The PaymentReturn message is sent by an agent to the previous agent in the payment chain to undo a payment previously settled.

### src-000163-pacs.004.001.15-p246-c002

src-000163, file page 246; 4 pacs.004.001.15 PaymentReturnV15.

> The PaymentReturn message is exchanged between agents to return funds after settlement of credit transfer instructions (that is FIToFICustomerCreditTransfer message and FinancialInstitutionCreditTransfer message) or direct debit instructions (FIToFICustomerDirectDebit message).

### src-000163-pacs.004.001.15-p246-c003

src-000163, file page 246; 4 pacs.004.001.15 PaymentReturnV15.

> The PaymentReturn message should not be used between agents and non-financial institution customers.

### src-000163-pacs.007.001.14-p562-c001

src-000163, file page 562; 5 pacs.007.001.14 FIToFIPaymentReversalV14.

> The FinancialInstitutionToFinancialInstitutionPaymentReversal message is sent by an agent to the next party in the payment chain.

### src-000163-pacs.007.001.14-p562-c002

src-000163, file page 562; 5 pacs.007.001.14 FIToFIPaymentReversalV14.

> The FIToFIPaymentReversal message is exchanged between agents to reverse a payment message that has been settled.

### src-000163-pacs.008.001.14-p702-c001

src-000163, file page 702; 6 pacs.008.001.14 FIToFICustomerCreditTransferV14.

> The FinancialInstitutionToFinancialInstitutionCustomerCreditTransfer message is sent by the debtor agent to the creditor agent, directly or through other agents and/or a payment clearing and settlement system.

### src-000163-pacs.008.001.14-p702-c003

src-000163, file page 702; 6 pacs.008.001.14 FIToFICustomerCreditTransferV14.

> The FIToFICustomerCreditTransfer message is exchanged between agents and can contain one or more customer credit transfer instructions.

### src-000163-pacs.008.001.14-p702-c004

src-000163, file page 702; 6 pacs.008.001.14 FIToFICustomerCreditTransferV14.

> If the instructing agent and the instructed agent wish to use their direct account relationship in the currency of the transfer then the message contains both the funds for the customer transfer(s) as well as the payment details;

### src-000163-pacs.008.001.14-p702-c005

src-000163, file page 702; 6 pacs.008.001.14 FIToFICustomerCreditTransferV14.

> If the instructing agent and the instructed agent have no direct account relationship in the currency of the transfer, or do not wish to use their account relationship, then other (reimbursement) agents will be involved to cover for the customer transfer(s).

### src-000163-pacs.008.001.14-p702-c006

src-000163, file page 702; 6 pacs.008.001.14 FIToFICustomerCreditTransferV14.

> The FIToFICustomerCreditTransfer contains only the payment details and the instructing agent must cover the customer transfer by sending a FinancialInstitutionCreditTransfer to a reimbursement agent.

### src-000163-pacs.009.001.13-p830-c001

src-000163, file page 830; 7 pacs.009.001.13 FinancialInstitutionCreditTransferV13.

> The FinancialInstitutionCreditTransfer message is sent by a debtor financial institution to a creditor financial institution, directly or through other agents and/or a payment clearing and settlement system.

### src-000163-pacs.009.001.13-p830-c003

src-000163, file page 830; 7 pacs.009.001.13 FinancialInstitutionCreditTransferV13.

> The FinancialInstitutionCreditTransfer message is exchanged between agents and can contain one or more credit transfer instructions where debtor and creditor are both financial institutions.

### src-000163-pacs.010.001.06-p1016-c001

src-000163, file page 1016; 8 pacs.010.001.06 FinancialInstitutionDirectDebitV06.

> The FinancialInstitutionDirectDebit message is sent by an exchange or clearing house, or a financial institution, directly or through another agent, to the DebtorAgent.

### src-000163-pacs.010.001.06-p1016-c003

src-000163, file page 1016; 8 pacs.010.001.06 FinancialInstitutionDirectDebitV06.

> The FinancialInstitutionDirectDebit message is exchanged between agents and can contain one or more financial institution direct debit instruction(s) for one or more creditor(s).

### src-000163-pacs.028.001.07-p1049-c001

src-000163, file page 1049; 9 pacs.028.001.07 FIToFIPaymentStatusRequestV07.

> The FinancialInstitutionToFinancialInstitutionPaymentStatusRequest message is sent by the debtor agent to the creditor agent, directly or through other agents and/or a payment clearing and settlement system.

### src-000163-pacs.028.001.07-p1049-c003

src-000163, file page 1049; 9 pacs.028.001.07 FIToFIPaymentStatusRequestV07.

> The FIToFIPaymentStatusRequest message is exchanged between agents to request status information about instructions previously sent.

### src-000163-pacs.028.001.07-p1049-c004

src-000163, file page 1049; 9 pacs.028.001.07 FIToFIPaymentStatusRequestV07.

> Its usage will always be governed by a bilateral agreement between the agents.

### src-000163-pacs.028.001.07-p1049-c005

src-000163, file page 1049; 9 pacs.028.001.07 FIToFIPaymentStatusRequestV07.

> The FIToFIPaymentStatusRequest message can be used to request information about the status (such as rejection, acceptance) of a credit transfer instruction, a direct debit instruction, as well as other intra- agent instructions (for example FIToFIPaymentCancellationRequest).
